# ارزیابی کاربردپذیری پنل مدیریت و داشبورد مشتری + برنامه کاهش ۵۰٪ پیچیدگی

## جمع‌بندی
در وضعیت فعلی، استفاده کامل پلتفرم برای صاحب کسب‌وکار غیرفنی **بدون آموزش** دشوار است؛ مخصوصاً در پنل مدیریت فروشنده/ادمین.

---

## ارزیابی معیارها

### 1) پیچیدگی منوها
- **وضعیت:** بالا
- **مشکل:** آیتم‌های زیاد و چندلایه (به‌خصوص حسابداری)
- **اثر:** کاربر نمی‌داند از کجا شروع کند
- **محل:** `Views/Shared/_ShopAdminLayout.cshtml`

### 2) یکپارچگی نام‌گذاری
- **وضعیت:** متوسط رو به ضعیف
- **مشکل:** واژه‌های تخصصی/ناهمگن
- **اثر:** افزایش بار شناختی
- **محل:** `Views/Shared/_AdminLayout.cshtml`, `Views/Admin/Index.cshtml`, `Views/ShopAccount/Profile.cshtml`

### 3) تعداد کلیک موردنیاز
- **وضعیت:** متوسط
- **مشکل:** مسیرهای پراکنده برای اقدامات کلیدی
- **اثر:** کندی انجام کار
- **محل:** منوها + صفحات Setup

### 4) قابلیت کشف ویژگی‌ها
- **وضعیت:** متوسط رو به ضعیف
- **مشکل:** برخی امکانات در زیرمنوها پنهان هستند
- **اثر:** کاربر قابلیت‌ها را پیدا نمی‌کند
- **محل:** `Views/Shared/_AdminLayout.cshtml`, `Views/Shared/_ShopAdminLayout.cshtml`

### 5) بار شناختی
- **وضعیت:** بالا
- **مشکل:** گزینه‌های زیاد + اصطلاحات تخصصی + نبود مسیر اقدام بعدی
- **اثر:** وابستگی به آموزش

### 6) طراحی داشبورد
- **وضعیت:** متوسط
- **مشکل:** یکدستی اکشن‌ها/کارت‌ها کم است
- **اثر:** رفتار غیرقابل پیش‌بینی
- **محل:** `Views/ShopAdmin/Index.cshtml`, `Views/Admin/Index.cshtml`

### 7) Empty States
- **وضعیت:** ناقص
- **مشکل:** در برخی لیست‌ها CTA یا توضیح کافی نیست
- **اثر:** کاربر در وضعیت خالی متوقف می‌شود
- **محل:** `Views/ShopAdmin/Index.cshtml`, `Views/ShopAccount/Orders.cshtml`

### 8) پیام‌های خطا
- **وضعیت:** متوسط
- **مشکل:** پیام‌ها همیشه عملیاتی نیستند (قدم بعدی مشخص نیست)
- **اثر:** تکرار خطا

### 9) متون راهنما
- **وضعیت:** متوسط
- **مشکل:** فیلدهای تخصصی برای کاربر عمومی شفاف نیست
- **اثر:** خطای ورودی
- **محل:** `Views/ShopAccount/Profile.cshtml`

### 10) Onboarding
- **وضعیت:** قابل قبول اما ناکافی
- **مشکل:** Setup هست ولی هدایت خطی قوی نیست
- **اثر:** فعال‌سازی کند
- **محل:** `Views/ShopAdmin/Setup.cshtml`, `Views/ShopAdmin/Index.cshtml`

## برنامه کاهش ۵۰٪ پیچیدگی

### A) ساده‌سازی منو (اولویت ۱)
- کاهش آیتم‌های حسابداری به ۴ گروه:
  1) نمای کلی
  2) فروش/خرید
  3) بانک و صندوق
  4) گزارش‌ها
- انتقال راهنماها به یک بخش واحد: «راهنما»
- تغییر نام `Setup` به «شروع سریع» و پین شدن تا تکمیل مراحل

### B) یکپارچه‌سازی زبان UI (اولویت ۱)
- جایگزینی واژه‌های تخصصی با عبارات ساده
- تعریف دیکشنری ثابت واژگان و استفاده یکسان در کل پنل

### C) کاهش کلیک و افزایش کشف‌پذیری (اولویت ۲)
- افزودن «۳ اقدام بعدی» در داشبورد
- افزودن Breadcrumb و توضیح کوتاه «این صفحه چه کاری می‌کند؟»

### D) استانداردسازی Empty State (اولویت ۲)
- الگوی ثابت برای همه لیست‌ها:
  - چرا خالی است؟
  - قدم اول چیست؟
  - یک CTA اصلی

### E) Onboarding خطی و مرحله‌ای (اولویت ۱)
- تبدیل Setup به Wizard واقعی
- Step مشخص + دکمه «مرحله بعد»
- درصد پیشرفت + چک‌لیست روشن

## خروجی مورد انتظار
- کاهش سردرگمی کاربر غیرفنی
- افزایش سرعت رسیدن به «اقدام ارزشمند اول»
- کاهش نیاز به آموزش/پشتیبانی اولیه
- افزایش نرخ فعال‌سازی و تبدیل Trial به Paid
